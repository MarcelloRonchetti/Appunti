Access Control List (ACL)

Filtri di traffico applicati sulle interfacce dei router. Standard, estese, wildcard, firewall.

Sicurezza

🛡️ Cosa sono le ACL

Una Access Control List è una lista ordinata di regole permit / deny applicate al traffico che entra (in) o esce (out) da un'interfaccia di router. Il router controlla ogni pacchetto contro le regole in ordine e applica la prima che fa match.

Regola implicita finale: deny any any. Tutto ciò che non è esplicitamente permesso viene scartato.

Posizionamento:

  • ACL standard: il più vicino possibile alla destinazione (filtrano solo per IP sorgente, quindi se messe vicino alla sorgente bloccherebbero anche traffico legittimo).
  • ACL estese: il più vicino possibile alla sorgente (filtrano per IP, protocollo, porte → si possono mettere all'origine senza danni collaterali, riducendo carico sulla rete).

✳️ Wildcard mask — l'inverso della subnet mask

Le ACL usano una wildcard mask per esprimere range di IP. Funziona al contrario della subnet mask:

  • Bit a 0: il bit corrispondente dell'IP deve corrispondere (controllo esatto).
  • Bit a 1: il bit corrispondente dell'IP può essere qualsiasi cosa (don't care).

Esempi:

  • 0.0.0.0 → host singolo (sinonimo di host)
  • 0.0.0.255 → tutta una /24 (es. 192.168.1.0 0.0.0.255 = 192.168.1.0/24)
  • 0.0.0.3 → 4 IP consecutivi (/30)
  • 255.255.255.255 → tutti gli IP (sinonimo di any)

Trucco: wildcard = 255.255.255.255 − subnet mask. Es. /24 → 255.255.255.0 → wildcard 0.0.0.255.

ACL Standard

Filtra solo su IP sorgente

Numerate 1–99 e 1300–1999. Sintassi semplice.

! permette solo dalla rete 192.168.10.0/24 access-list 10 permit 192.168.10.0 0.0.0.255 access-list 10 deny any interface g0/1 ip access-group 10 out
ACL Estese

Filtra su IP src/dst, protocollo, porte

Numerate 100–199 e 2000–2699. Granularità massima.

! permette HTTPS verso il web server access-list 110 permit tcp 192.168.10.0 0.0.0.255 host 10.0.0.5 eq 443 ! blocca tutto il resto verso il server access-list 110 deny ip any host 10.0.0.5 access-list 110 permit ip any any interface g0/0 ip access-group 110 in

🔥 ACL come firewall

Con una sequenza di ACL estese sui router perimetrali si realizza un firewall stateless:

  • Si permettono solo i servizi necessari (web, mail, DNS).
  • Si bloccano protocolli di management dall'esterno (telnet, SSH se non da IP fidati).
  • Si applicano regole anti-spoofing: pacchetti con IP sorgente privato che arrivano da fuori → deny.

Limite: stateless = non tiene traccia delle connessioni. Per stateful inspection si passa a firewall dedicati (es. Mikrotik con connection-state established/related).
